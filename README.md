# KTN Shoes

KTN Shoes est un projet de site e-commerce dédié à la vente de chaussures pour femmes, hommes et enfants. Le site permet aux utilisateurs de découvrir un catalogue de produits, de consulter les détails d'une chaussure et de gérer leurs articles dans un panier.

Le projet est développé sans framework et sans backend réel. L'objectif est de mettre en pratique les fondamentaux du développement web avec HTML5, CSS3 et JavaScript, tout en construisant progressivement une interface moderne, responsive et interactive.

Les données des produits sont stockée localement dans le fichier `produits.js`. La gestion du panier est réalisée côté client, avec les données conservées en mémoire à l'aide de localStorage afin de permettre leur persistance dans le navigateur.
